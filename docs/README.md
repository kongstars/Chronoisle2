# 文档导航

`docs/` 按用途分层，默认从这里开始找资料。

## 核心文档

- `core/development.md`: 开发文档，记录技术方案、实现状态和工程约束
- `core/product.md`: 产品文档，记录已实现能力与待优化方向
- `core/todo.md`: 代办清单，记录优先级和执行状态

## 设计文档

- `design/ui/`: UI 主规范、页面规范、视觉 token、线框和重构计划
- `design/harmonyos/`: HarmonyOS NEXT 适配总纲、矩阵和升级方案
- `design/resources/`: 资源采用清单与资源边界说明
- `design/ui/ui-style-guide.md`: 当前可执行的 UI 主规范

## 恢复与历史整理

- `recovery/RECOVERY_CHECKLIST.md`: 历史恢复清单
- `plans/`: 重构计划和专项改造方案
- `widgets/`: 桌面卡片实现记录

## 运维与参考

- `ops/`: 运维和环境相关文档
- `reference/`: 第三方声明、参考性说明文档
- `licenses/`: 许可证和授权文本

## 其他资料

- `guides/`: 临时修复指南或排障说明
- `软著申请材料/`: 软著准备材料
