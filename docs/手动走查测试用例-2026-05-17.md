## 测试用例 1：注册新账号

**路径**：SplashPage → LoginPage → RegisterPage

| 步骤 | 操作 | 预期结果 | 实际结果 |
|------|------|----------|----------|
| 1.1 | 冷启动应用 | 显示 SplashPage（Logo + 加载动画），1-2 秒后自动跳转到 LoginPage | |
| 1.2 | 确认 LoginPage 显示完整 | 页面有"登录"标题、手机号输入框、获取验证码按钮、第三方登录入口、底部"注册"链接 | |
| 1.3 | 点击"注册账号" | 跳转到注册页，标题为"注册"，有手机号输入框、验证码输入框、密码输入框 | |
| 1.4 | 输入手机号（使用真实可用号码） | 输入框正常响应，数字键盘弹出 | |
| 1.5 | 点击"获取验证码" | 按钮变为倒计时（60s），手机收到短信验证码。如果收不到 → **记录为问题** | |
| 1.6 | 输入收到的验证码 | 输入框正常 | |
| 1.7 | 输入密码（8位以上，含字母数字） | 输入框正常，密码显示为 `••••` | |
| 1.8 | 点击"注册"按钮 | 显示 loading，注册成功后自动跳转到 MainPage（主页）—— 不应停留在注册页 | |
| 1.9 | 确认底部导航可见 | 主页底部有导航栏（今日 / 任务 / 日历 / 统计 / 我的） | |

**关键检查**：
- 注册成功后是否自动登录？是否跳转到主页？
- 如果注册失败（号码已注册等），是否有 toast 提示？错误信息是否清晰？
