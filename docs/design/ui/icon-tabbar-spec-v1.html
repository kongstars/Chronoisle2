状态策略

标准 Tab

今日、行动、目标、我的在未选中时使用轮廓表达，在选中时使用同骨架下的局部或主体填充，避免只靠颜色区分。

语音按钮

语音默认态应是弱强调，不应在未激活时长期压过四个普通 Tab。展开或进入语音态时再切到更强存在感。
