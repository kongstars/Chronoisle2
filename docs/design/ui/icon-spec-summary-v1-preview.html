图标规范汇总预览 V1

这是一页面向评审和交付的汇总预览，把图标系统的核心原则、底部 Tab 规则、分组范围和关联产物集中展示。

核心原则
形态统一，颜色分层，少量场景个性。
实施边界
只改 icon，不改布局，不借容器结构补效果。
落地方向
继续以 `AppIcon` 为唯一入口，避免页面层继续分散。
设计方向 尺寸与描边 颜色体系 状态规则 底部 Tab 规范 图标分组 位图资源策略 关联文档与预览
如果要继续推进到开发实现，这页可以作为设计和开发的共同入口页，再配合 Markdown 规范和草图板一起使用。

设计方向

先对齐图标系统的审美方向和边界，避免后续细节失焦。

Core

总体原则

统一网格、描边、转角和留白规则；通过少量场景化图标保留产品记忆点。

视觉边界

不做 3D、不做厚重发光、不做写实拟物，保持线性骨架为主，必要时局部实体化。

实施边界

严格遵守“只改 icon，不改布局”，不通过位置、尺寸或容器变化掩盖图形问题。

尺寸与描边

控制尺寸层级和线条粗细，是统一感最重要的基础。

Token
层级 尺寸 用途
微状态 12 点标、极小提示、优先级
行内状态 16 勾选、列表状态、小反馈
小控件 20 工具按钮、次级入口
标准操作 24 导航、按钮 icon、Tab icon
卡片主图标 32 业务主语义、卡片头部
空态 / Hero 40 / 48 引导、空态、品牌强化

小尺寸描边

1.5 - 1.65，优先保清晰，不追求复杂轮廓。

标准描边

1.75 - 1.9，覆盖大部分 `20 / 24` 的操作与导航 icon。

大尺寸描边

2，用于 `32` 及以上的大图标、卡片主语义和空态。

颜色体系

不是所有 icon 都统一色，而是“统一骨架 + 分层配色”。

Color
Neutral Ink Brand Cyan Growth Green Warning Amber Focus Indigo Tomato Coral Joy Rose

统一比例

80% 统一，20% 个性。高频操作优先统一色。

状态反馈

成功、提醒、信息类走固定语义色，不跟着页面随意漂移。

场景个性

`ai`、`focus`、`voice`、`tomato`、`joy` 允许保留少量识别色。

用色红线

不能让每个业务 icon 都独立上色，否则整体会重新失控。

状态规则

激活态不能只靠颜色，默认态也不能太重。

State

默认态

轮廓型、较轻、语义清晰，是大多数 icon 的常态。

激活态

同骨架下强化，优先采用局部实体化、局部填充、核心形体强化。

不推荐

只换颜色、完全换另一枚图标、或激活时整体变粗一整级。

底部 Tab 规范

底栏图标必须有明确的选中 / 未选中图形差异，且不改变布局。

Tab Bar

今日 / 行动 / 目标 / 我的

前四个 Tab 必须同时具备 `图形差异 + 颜色差异`。未选中态保持线性轮廓，选中态在同骨架下做实体化或局部填充。

语音按钮

语音不参与普通 Tab 的选中逻辑。默认态应是“弱强调”，激活或展开时再进入“强强调”，避免长期抢占底栏第一视觉焦点。

Tab 未选中态 选中态
今日 线框日历 实体日历底板 + 白色今日点
行动 线性闪电 实体闪电
目标 双环靶心 实体外圈 + 保留靶心中心
我的 线框头像 实体头像与肩部轮廓
语音 独立按钮，弱强调 激活 / 展开时增强
