岛屿晨曦浅深模式样张

你说得对，上一版其实是两个完全不同的主题。这次我把 `A · 岛屿晨曦` 作为唯一母主题，再延展出一个同源深色模式，让浅色和深色共享同一套情绪与品牌语言。

浅色模式：岛屿晨曦 清晨沙色底、柔和紫主色、晨光橙点缀。它的气质是松弛、温暖、鼓励开始，不强调压迫感。
深色模式：岛屿夜航 不是冷科技蓝，也不是另一个工作台主题，而是把晨曦延续到夜色里。背景转成深紫褐夜空，主色变成月光紫，点缀保留暮光橙。

同一个主题的两种时段

浅色像清晨上岛，深色像夜里返航。两边都保留了温柔、陪伴和生活化的气质，只是一个偏“开始今天”，一个偏“收束今天”。这样才是同一主题下合理的浅深模式关系。
