# Chronoisle UI System V2 核心设计规范 (高密精工版)

> 本规范基于 `ai-light-tech-premium` 与 `ai-dark-tech-premium` 样张总结，是指导本项目 ArkUI 重构的最高视觉准则。

## 1. 核心设计理念

- **高密无界 (Dense & Borderless)**：消除多余的容器内边距 (Padding) 和生硬的分割线，让内容直接铺展。
- **微雕精工 (Micro-textures)**：大量使用极其轻微的内发光 (Inner Glow)、多层阴影 (Composite Shadows) 和虚化线条，模拟高品质物理仪器的质感。
- **点阵科技底纹 (Dot-matrix Pattern)**：在全局纯色背景之上，必须叠加微弱的点阵网格，作为“轻科技感”的底层视觉暗示。
- **克制的霓虹感 (Neon Accents)**：在极简的黑/白灰底色上，仅在 AI 焦点、优先级提示等极少数地方使用高饱和度的极光渐变或荧光色。
- **效率优先 (Crisp Animation)**：去除所有不必要的 Hover 动效，全面采用清脆跟手的 **“按压微缩放 (Scale 0.96 / 0.92)”** 物理反馈。动效时长统一为极速的 `100ms`。

## 2. 空间与布局极限 (Layout & Spacing)

V2 版本的核心特征是对空间的极限压榨，任何多余的留白都视为“浪费”。

- **全局模块间距 (Section Gap)**: `16px` (取代之前的 24px)
- **卡片内边距 (Card Padding)**: `12px` (取代之前的 16px)
- **卡片/列表圆角 (Border Radius)**:
  - 外部大容器: `14px` (radius-lg)
  - 内部独立卡片: `10px` (radius-md)
  - 微小元素 (按钮/标签/复选框): `6px` (radius-sm)
- **列表无界化 (Borderless List)**：当多个列表项同处于一个大容器中时，**内部元素紧贴边缘，取消左右 Padding 限制**。

## 3. 色彩体系 (Color System)

V2 不再使用扁平的单色块，而是大量引入微妙的渐变和半透明层次。

### 浅色模式 (Light Mode)
- **背景层**: `#F0F2F7` (带有极其轻微的冷灰色调，不是纯白)
- **表面层**: `#FFFFFF` 到 `#FAFBFC` 的微弱向下渐变
- **主品牌色**: `#5B5CE6`
- **AI 极光渐变**: `linear-gradient(135deg, #5B5CE6 0%, #00C6FF 100%)`
- **文本层级**:
  - Primary: `#14151A`
  - Secondary: `#525666`
  - Muted: `#8E93A6`

### 深色模式 (Dark Mode)
深色模式并非简单的反色，而是追求“深空感”与“赛博感”。
- **背景层**: `#0D0E12` (深空蓝黑)
- **表面层**: `#1A1B23` (带有轻微玻璃反光的深色表面)
- **主品牌色 (提亮)**: `#7A7CFF` (提高饱和度以适应深色背景)
- **AI 极光渐变**: `linear-gradient(135deg, #7A7CFF 0%, #00D4FF 100%)`
- **文本层级**:
  - Primary: `#F3F4F8`
  - Secondary: `#A0A4B8`
  - Muted: `#6B6F85`

## 4. 阴影与光效 (Shadows & Lighting)

这是拉开 V2 质感差距的核心。绝不能只用原生的 `box-shadow: 0 4px 10px rgba(0,0,0,0.1)`。

### 浅色模式阴影
- **复合悬浮阴影 (Shadow Card)**: 
  - 包含两层外阴影 (弥散+实体)
  - **关键点**: 必须包含一层 `inset 0 1px 0 rgba(255,255,255,0.8)` 的顶部内发光，制造高光边缘。
- **按钮微光 (Shadow Btn)**:
  - 带有主色调的彩色投影，如 `rgba(91, 92, 230, 0.15)`。

### 深色模式阴影 (发光为主)
- **深色悬浮阴影 (Shadow Card)**:
  - 外层是极重的黑色投影 `rgba(0,0,0,0.4)`
  - **关键点**: 必须包含一层 `inset 0 1px 1px rgba(255,255,255,0.06)` 的内描边，这是深色模式独有的 **边缘高光 (Rim Lighting)**。
- **深色按钮发光 (Shadow Btn)**:
  - 彩色发光投影 `rgba(122, 124, 255, 0.3)`，模拟霓虹灯效。

## 5. 分割线与装饰 (Dividers & Ornaments)

- **渐隐分割线**: 列表项之间的底边线，不能是通栏实线。必须是**两端透明、中间实色**的渐变线条。
- **AI 流光边缘**: 重点关注的卡片（如目标进度），顶部边缘叠加一条极细的（2px）极光渐变条，左右两端自然淡出。
- **等宽数字**: 所有的进度百分比、时间标签，必须强制使用等宽字体 (`SF Mono`, `Consolas`, 或 `monospace`)，增强仪器感。
