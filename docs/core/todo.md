# Chronoisle2 代办清单

更新时间：2026-04-27
文档定位：记录当前项目的待办事项、优先级和执行状态。本文档应与 `docs/core/product.md`、`docs/core/development.md` 同步维护。

## 当前阶段判断

项目已完成核心功能恢复和多条 AI/会员/卡片链路的代码接入。当前重点不是继续堆新功能，而是完成近期大改动的验收、自动化和一致性收敛。

近期最关键的风险集中在：

- 华为自动续期会员已经接入代码，但缺少沙盒订单和通知回调验收。
- 语音创建已经形成新主链路，但字段状态、低置信度策略和自动化断言仍未闭环。
- 今日计划和 AI 重排都强化了 AI 决策能力，需要用真实边界数据验证不会误导或误操作用户。
- 桌面卡片和全局 UI 规范仍处于“代码迁移完成一部分，系统级体验待确认”的阶段。

## P0：必须优先完成

### P0-1 华为自动续期会员验收

状态：待执行
相关文档：`docs/ops/huawei-iap-autorenewal.md`

必须完成：

- 在华为沙盒环境验证月度连续包月购买。
- 在华为沙盒环境验证年度连续包年购买。
- 验证服务端 `POST /api/iap/verifyOrder` 购买凭证验签和订单幂等。
- 验证 `POST /api/iap/huawei/notify` 对续期、取消、退款、撤销、到期事件的处理。
- 验证 `IapOrder`、`IapEvent`、会员有效期和积分发放记录是否一致。
- 验证重复通知、乱序通知、未知商品、未知订阅号和人工复核状态。
- 上线前完成密钥轮换、环境变量隔离和生产通知 URL 检查。

完成标准：

- 沙盒全链路通过。
- 服务端日志能定位每一笔订单和通知事件。
- 会员页状态与服务端会员状态一致。
- 异常事件不会重复发放权益。

### P0-2 语音创建系统化闭环

状态：进行中
相关文档：`docs/plans/voice-create-refactor-plan.md`

必须完成：

- 抽象统一 `AIFillState`，让任务、提醒、专注创建页复用同一套 AI 填入状态。
- 明确字段填入、用户手动修改、AI 重新解析、隐藏提示之间的状态流转。
- 把 `server/tests/fixtures/voice-create-cases.json` 转成可执行断言脚本。
- 覆盖空文本、低置信度、噪音文本、改意图、字段冲突、服务端超时和缓存命中。
- 真机验证录音、转写、确认文本、跳转创建页、字段填入和遥测 `traceId`。

完成标准：

- 语音创建的分类、解析和创建页填入都有自动化回归样例。
- 创建页不会覆盖用户手动编辑字段。
- 低置信度或解析失败时有稳定降级路径。
- 真机链路可复现并有日志可追踪。

### P0-3 桌面卡片真机验收

状态：待执行

必须完成：

## 维护规则

- 每次代码出现较大变更时，必须更新本代办。
- P0 只放会阻断发布、验收或核心体验闭环的事项。
- P1 放近期应做、但不一定阻断主链路运行的事项。
- P2 放体验增强、运营完善和长期优化事项。
- 已完成事项必须写清完成日期。
- 不能把“代码已接入”误写成“已验收完成”。
