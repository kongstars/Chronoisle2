# Chronoisle2 产品文档

更新时间：2026-04-27
文档定位：记录当前产品已经实现的能力、仍需优化的功能，以及每天的产品侧进展。本文档需要随代码改动持续维护。

## 1. 产品定位

Chronoisle2 是一个以“任务、提醒、目标、专注、智能规划”为核心的个人效率应用。

产品目标：

- 帮助用户把长期目标拆解成可执行任务。
- 通过提醒、番茄钟、日历和打卡机制提升执行稳定性。
- 使用 AI 辅助生成计划、复盘任务、语音创建事项和重排积压任务。
- 通过桌面卡片、会员体系、成就体系和统计看板提升长期使用黏性。

## 2. 当前已实现的功能

### 2.1 核心任务与提醒

- 支持任务创建、编辑、完成、归档、延期和状态管理。
- 支持一次性提醒、倒计时提醒、周期提醒和每日打卡类提醒。
- 支持任务与目标、关键结果、提醒、日历事件之间的基础关联。
- 支持搜索页和入口页的空状态控制，未输入关键词时保持页面为空，避免默认噪音。
- 支持打卡页按日期聚合提醒、任务和日程，并保留紧急程度颜色语义：
  - 绿色：未到期。
  - 黄色：未来 1-2 天到期。
  - 红色：已逾期或今天到期。

### 2.2 目标与关键结果

- 支持目标创建、编辑、删除、完成、归档。
- 支持目标类型、关键结果、目标进度和目标详情页展示。
- 支持从目标拆分任务，并在任务、目标和重排流程中保留来源关系。
- 目标页面已纳入新的全局视觉规范，强调层级、结构化和执行导向。

### 2.3 今日页与今日计划

- 今日页支持当天任务、提醒、专注入口、AI 今日计划和底部导航。
- 今日计划已区分 `local`、`cloud_pending`、`cloud_adopted` 等来源状态。
- 云端 AI 生成的今日计划可以先进入待采纳状态，用户确认或调整后再采纳。
- 今日计划展示任务入选原因、分组信息、来源标记和采纳状态，避免“AI 直接覆盖当天安排”。
- 服务端计划调度已按上海日期执行，并优先保留今天已承诺和逾期未完成任务。

### 2.4 AI 能力

- 已恢复并验证 19 条服务端/本地联动链路，包括目标规划 Trace、AI 今日计划、AI 重排、语音创建、会员、积分、遥测等主链路。
- AI 目标规划支持 Trace 查看页，用于追踪规划过程。
- AI 今日计划支持云端生成、待采纳、采纳落库和使用次数扣减。
- AI 重排支持对逾期任务进行完整覆盖分析，并区分专注、延期、降级、搁置、删除等建议。
- AI 重排删除建议已改为用户显式选择后再应用，降低误删风险。
- 语音创建已从“单次弹层识别”升级为系统化创建链路：
  - 支持录音转写后的确认/编辑步骤。
  - 支持本地规则和服务端分类快速判断任务、提醒、目标、专注等意图。
  - 支持携带 `traceId` 进入后续创建页。
  - 任务、提醒、专注创建页已接入后台字段解析和 AI 填入提示。
  - 服务端已拆分 `classify`、`parse`、`analyze` 能力，并引入按用户隔离的解析缓存。

### 2.5 会员与积分

- 支持会员状态查询、积分查询和会员权益展示。
- 已接入华为 IAP 基础购买校验链路。
- 已新增华为自动续期订阅主链路：
  - 月度连续包月和年度连续包年商品 ID 已通过配置集中管理。
  - 客户端按自动续期商品类型查询商品并发起购买。
  - 服务端支持购买凭证验签、订单幂等发放、会员权益更新和月度积分发放。
  - 服务端支持华为订阅通知入口，覆盖购买、续期、取消、退款、撤销、到期等状态事件。
- 自动续期仍需要沙盒订单、通知回调和异常状态的端到端验收后才能标记为发布完成。

### 2.6 专注、番茄钟与统计

- 支持创建专注会话、番茄钟记录和专注统计。
- 支持从语音创建进入专注创建页，并尝试解析标题、时长和关联任务。
- 专注页面已接入 AI 填入提示组件，减少语音创建后的字段理解成本。

### 2.7 桌面卡片与系统入口

- 已实现多个 HarmonyOS Form 桌面卡片，包括主卡片、焦点卡片、提醒卡片、目标卡片、统计卡片等。
- 卡片数据装配已集中到 `EntryFormAbility`、`WidgetFormDataService`、`WidgetRefreshService` 等服务。
- 卡片页面保持绑定式展示，避免在卡片 UI 内直接读取应用偏好或上下文。
- 已新增统一的 `WidgetStyle`，卡片颜色、圆角、字号和间距开始集中管理。
- 卡片真机显示、点击跳转、刷新频率和不同尺寸体验仍需系统级验收。

### 2.8 UI 与设计规范

- 已新增全局 UI 风格体系文档，作为当前最高优先级 UI 规范。
- 当前视觉方向为：克制、精致、结构清晰、轻科技感、效率工具密度。
- 页面结构统一按 L1 容器、L2 功能区、L3 操作控件组织。
- 多个页面已开始迁移到统一基础组件和样式体系，包括按钮、徽章、搜索栏、Hero 区块、AI 填入提示、任务行和卡片样式。
- 底部导航、打卡页、提醒页、目标页、统计页、会员页等核心页面已完成多轮视觉和交互整理。

## 3. 仍需优化的功能

### 3.1 语音创建系统

- 需要补齐统一的 `AIFillState`，替代各创建页分散维护 `Set<string>`、状态文案和用户编辑保护逻辑。
- 需要把语音创建 fixture 转成可执行的自动化断言脚本，覆盖分类、字段解析、错误码和低置信度场景。
- 低置信度意图、空转写、噪音文本和用户中途改意图的交互策略仍需打磨。
- 需要在真机上验收录音、转写、确认、跳转、字段填入和遥测链路。

### 3.2 华为自动续期会员

- 需要在华为沙盒环境完成月包、年包、续期、取消、退款、撤销、到期事件验收。
- 需要验证通知回调的签名、幂等、乱序事件处理和人工复核状态。
- 上线前需要完成密钥轮换、环境变量隔离和生产回调地址配置检查。

### 3.3 今日计划

- 需要验证凌晨调度在真实账号、多时区边界、逾期任务较多和重复周期提醒场景下的稳定性。
- 待采纳计划的编辑、采纳、放弃、重新生成和本地修改冲突仍需补齐回归用例。
- 任务入选原因和分组说明需要继续优化为更易读的产品文案。

### 3.4 AI 重排

- 需要针对跨目标同名任务、自动周期提醒、依赖顺序、删除建议选择应用等场景补充回归用例。
- 需要继续观察“完整覆盖所有逾期任务”要求是否会导致 AI 建议过重或分组不自然。
- 删除、搁置、降级等高风险操作需要更明确的预览、撤销和审计提示。

### 3.5 桌面卡片

- 需要真机验证所有尺寸卡片的渲染、刷新、跳转和系统限制。
- 需要继续压缩卡片逻辑，保持卡片 UI 只负责展示，数据在服务层装配。
- 需要验证桌面卡片在无数据、登录过期、权限异常时的降级体验。

### 3.6 UI 统一与体验债务

- 新全局 UI 规范需要继续落到所有历史页面，避免旧页面与新页面风格断裂。
- ArkTS 编译警告、重复样式、重复空状态和旧组件调用仍需持续清理。
- 日历、提醒、任务和目标之间的信息架构仍可继续压缩，减少重复入口。
