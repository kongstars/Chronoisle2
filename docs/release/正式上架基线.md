# 正式上架基线

## 目标

用于在提交 AppGallery 审核前，统一确认当前版本的代码、配置、物料、测试与运维基线，避免多份清单状态不一致。

## 发布信息

- 应用名称：四时清单
- 版本号：`待填写`
- Build 号：`待填写`
- 提审日期：`待填写`
- 提审负责人：`待填写`
- 发布负责人：`待填写`
- 服务端版本/提交：`待填写`
- 客户端版本/提交：`待填写`

## P0 阻断项

- [ ] 登录主链路在生产环境可用
- [ ] 账号注销接口可用并完成真机验证
- [ ] IAP 商品、验单、通知回调已完成沙箱验收
- [ ] Release 签名包可安装、可启动、可支付
- [ ] 隐私政策、用户协议、账号注销说明已定稿
- [ ] 备案/资质项已完成或具备提审前置条件

## 客户端基线

- [ ] `entry/` Release 构建成功
- [ ] 版本号、应用名、图标、启动页已确认
- [ ] 登录/退出登录/重新登录通过
- [ ] 新用户引导通过
- [ ] 目标/提醒/任务/今日计划主路径通过
- [ ] 搜索、统计、会员页通过
- [ ] 账号注销页和注销结果通过
- [ ] 深浅色主题表现正常
- [ ] 弱网/无网/接口失败有正确提示

## 服务端基线

- [ ] 生产环境变量齐全
- [ ] `JWT_SECRET` 已配置
- [ ] MongoDB 连通且备份策略已确认
- [ ] `/health` 正常
- [ ] `/api/auth/*` 正常
- [ ] `/api/sync/*` 正常
- [ ] `/api/iap/*` 正常
- [ ] `/api/telemetry/*` 正常
- [ ] 账号注销数据清理日志可追踪

## IAP 基线

- [ ] AppGallery 商品已创建并启用
- [ ] 月订阅商品 ID 已确认
- [ ] 年订阅商品 ID 已确认
- [ ] 客户端商品映射与服务端配置一致
- [ ] 沙箱账号可完成购买
- [ ] 恢复购买通过
- [ ] 续费通知通过
- [ ] 取消续费后状态回落通过
- [ ] 退款/撤销后的权益回收通过

## 合规基线
