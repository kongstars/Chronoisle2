> 关联文档：`docs/APPGALLERY_LAUNCH_CHECKLIST.md`、`docs/core/todo.md`、`docs/ops/huawei-iap-autorenewal.md`、`docs/软著申请材料/`。

## 阶段说明与依赖

| 阶段 | 主题 | 阻断后续 | 预计耗时 |
| --- | --- | --- | --- |

| B | 应用签名 & AGC 应用配置 | 阻断 Release 构建与提交 | 3-5 天 |

## 阶段 A：账号、资质、备案（外部审核驱动，最早启动）

### A1 华为开发者账号
- [ ] **A1.1** 确认账号主体（个人 / 企业）。企业账号需要营业执照，IAP 收款更顺畅；个人账号注册更快但部分能力受限。`负责：运营`
- [ ] **A1.2** 提交实名认证：身份证 / 营业执照 / 法人人脸识别。`负责：运营`
- [ ] **A1.3** 缴纳一次性注册费（个人 ¥99 起、企业 ¥800 起，以官方为准）。`负责：财务`
- [ ] **A1.4** 等待华为审核通过（1-3 个工作日）。`负责：运营`
- [ ] **A1.5** 在 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) 创建项目 `Chronoisle2`，并新建应用，填写包名 `com.sishiqingdan.app`。`负责：运营`


### A2 商户与支付资质
- [ ] **A2.1** 进入 AGC → 我的应用 → 增长 → 应用内支付，签署《华为应用内支付服务协议》。`负责：运营 / 法务`
- [ ] **A2.2** 绑定收款账户：企业对公账户或个人储蓄卡；准备开户行、账号、税号。`负责：财务`
- [ ] **A2.3** 等待银行打款验证（3-7 个工作日），完成商户开通。`负责：财务`
- [ ] **A2.4** 在商户后台开具发票模板（如需向用户开发票）。`负责：财务`

### A3 软件著作权登记（建议提前办理）
- [ ] **A3.1** 完善 `docs/软著申请材料/01-软著登记申请表-草稿.md` 与 `02-软件使用说明书-草稿.md`，根据 `00-填写前说明.md` 检查字段。`负责：运营`

- [ ] **A3.3** 个人申请准备《权属说明》（参考 `04-个人申请权属说明-模板.md`），公司申请准备劳动合同 / 委托证明。`负责：运营 / 法务`
- [ ] **A3.4** 在中国版权保护中心或地方版权局提交申请（电子流程约 30 个工作日，加急 5-15 个工作日另收费）。`负责：运营`
- [ ] **A3.5** 拿到《计算机软件著作权登记证书》，扫描存档。`负责：运营`
- [ ] **A3.6** 在 AGC 应用资质中上传软著证书（部分类目和支付类应用要求）。`负责：运营`

### A4 ICP 备案（域名 / 服务端必需）
- [ ] **A4.1** 确认服务端使用的域名是否已完成 ICP 备案。如服务部署在境内云（华为云 / 阿里云 / 腾讯云），可在云厂商控制台发起。`负责：运营`
- [ ] **A4.2** 准备主体材料：营业执照 / 身份证、法人核验、备案承诺书、域名证书。`负责：运营 / 法务`
- [ ] **A4.3** 提交至云厂商初审，再提交至省级管局审核（合计 5-20 个工作日）。`负责：运营`
- [ ] **A4.4** 拿到 ICP 备案号（如 `京ICP备XXXXXXXX号`），写入应用「关于」页和官网。`负责：客户端 / 运营`
- [ ] **A4.5** 30 天内完成「公安备案」（[全国互联网安全管理服务平台](https://www.beian.gov.cn/)），生成公安备案号。`负责：运营`
- [ ] **A4.6** 公安备案号在「关于」页和官网底部展示，并加链接跳转。`负责：客户端`

### A5 应用类合规备案
- [ ] **A5.1** 确认是否触发**移动互联网应用程序备案**（工信部 2024 起对所有 App 强制要求）。`负责：运营 / 法务`
- [ ] **A5.2** 通过华为 AGC 或工信部 ICP/IP 地址/域名信息备案管理系统提交 App 备案，需要软著、ICP 备案、应用签名 SHA-256 等材料。`负责：运营`
- [ ] **A5.3** 拿到 App 备案号，写入「关于」页（华为应用市场审核要求）。`负责：客户端`
- [ ] **A5.4** **算法备案**：本应用使用 AI 生成今日计划、AI 重排、语音意图分类，属于"生成合成类"和"个性化推送类"算法服务，需通过《互联网信息服务算法备案系统》备案。`负责：运营 / 法务`
- [ ] **A5.5** 准备算法备案材料：算法主体信息、算法基本原理说明、算法运行机制说明、安全自评估报告。`负责：运营 / 客户端 / 后端`
- [ ] **A5.6** 取得算法备案号，并在应用内 AI 功能页和隐私政策中披露。`负责：客户端 / 法务`
- [ ] **A5.7** 个人信息保护影响评估（PIA）报告：识别收集 PII 字段、跨境与第三方共享、风险与缓解措施。`负责：法务 / 后端`

> 备注：A5 各项任务有严格法规依据，存在不备案不能上架的硬阻断，建议在 A1-A2 通过后立刻启动。
